One sentence, one star, five stars for the food: an alien tourist reviews Earth.

> One star: Earth fined my ship for hovering, taxed my tentacles, and made me queue for oxygen — but the dumplings alone deserve a galaxy.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes that single sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22 standard library only, fully deterministic: same bytes on every run, no network, no clock, no randomness.
